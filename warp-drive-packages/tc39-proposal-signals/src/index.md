# @warp-drive/tc39-proposal-signals

Data bindings for the prototype [TC39 Signals](https://github.com/proposal-signals/signal-polyfill)
implementation. Its single entry point, [`install`](/api/@warp-drive/tc39-proposal-signals/install/),
configures ***Warp*Drive**'s reactivity to use the polyfill's `Signal.State` and `Signal.Computed`.
