module@warp-drive/core-types/schema/fields Legacy Package

Legacy package

@warp-drive/core-types is a legacy package. New code should use @warp-drive/core/types instead.

Legacy alias of @warp-drive/core/types/schema/fields. This entry re-exports that module unchanged so existing @warp-drive/core-types/schema/fields imports keep working; new code should import from @warp-drive/core/types/schema/fields directly.
