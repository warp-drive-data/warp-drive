# Installation

:::danger **We've moved!**
To install native types on an older release, follow [Pre-Migration (update to Native Types)](/upgrading/v5/index.md#pre-migration-update-to-native-types) in the 4.x to 5.x migration guide. The `warp-drive retrofit types` CLI is documented in the [`warp-drive` package README](https://github.com/warp-drive-data/warp-drive/blob/main/packages/-warp-drive/README.md#retrofit). Current packages ship their own types and need no setup: see [Installation](/guides/installation/index.md).
:::
