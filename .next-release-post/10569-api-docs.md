The API reference fills in documentation for a large number of previously undocumented public
types and members across `@warp-drive/core`, `@warp-drive/legacy`, `@warp-drive/utilities`,
`@warp-drive/ember` and `@warp-drive/react`: the `{json:api}` document, resource and relationship
types, cache mutations, operations and diffs, request options and `RequestInfo`/`ResponseInfo`,
the low-level reactivity primitives, schema field and trait types, and the legacy adapter,
serializer, `BuildURLMixin` and `AdapterError` APIs. Many of these pages now link union members and
related types to each other, so you can follow a type from one page to the next.
