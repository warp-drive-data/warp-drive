# Next Release Post

Summaries of changes waiting to be announced in the next release blog post, one markdown file per
pull request. A PR whose changelog label calls for one adds its file here; the PR that adds the
release's blog post under `blog/` deletes every file it used. This README is the only file that
stays.

See [Blog Summaries](https://canary.warp-drive.io/guides/contributing/submitting-prs#blog-summaries)
for which PRs need a file and how to write it.
