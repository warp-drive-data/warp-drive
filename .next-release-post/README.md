# Next Release Post

Summaries of changes waiting to be announced in the next release blog post, one markdown file per
pull request. Each file's `releases` frontmatter lists the release lines it ships on. The PR that
adds a release's blog post under `blog/` removes that release's line from the summaries it used,
and deletes a summary once its list is empty. This README is the only file that stays.

See [Blog Summaries](https://canary.warp-drive.io/guides/contributing/submitting-prs#blog-summaries)
for which PRs add a file, how to fill in `releases`, and how to write it.
